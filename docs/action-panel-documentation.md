# 动作面板（ActionPanel）文档

## 概述

动作面板是强化学习布局环境的核心组件，它定义了代理可以执行的所有动作。面板将各种UI操作组织为结构化的动作空间，使得强化学习算法可以通过这些动作探索和优化页面布局。

## 动作类型

动作面板支持以下核心动作类型：

### 1. 组件添加动作

- **描述**：从Markdown解析的元素中选择组件添加到布局中
- **动作特性**：
  - 保留元素原始属性和内容
  - 显示预设类型（例如h1、h2等）
  - 直接传递完整元素对象
- **代码实现**：`onAddComponent` 函数接收选定的父元素ID、元素类型和完整元素对象

### 2. 预设应用动作

- **描述**：将预设样式应用到选定元素
- **预设类别**：
  - 排版预设（h1, h2, h3, body等）
  - 布局预设（垂直居中、水平等）
  - 尺寸预设（自动、填充宽度等）
  - 外观预设（主色调、次色调等）
- **代码实现**：`onApplyCategoryPreset` 函数接收预设类别和预设键名

### 3. 核心属性修改动作

- **描述**：直接修改元素的核心CSS属性
- **可修改属性**：宽度、高度、外边距、内边距、背景色、文字颜色等
- **代码实现**：`onUpdateElementStyle` 函数接收元素ID、属性键和属性值

### 4. 移动元素动作

- **描述**：移动元素到新的位置
- **移动类型**：
  - 移动到容器：将元素移入另一个容器元素内
  - 同级移动：将元素移动到同级元素的前面或后面
- **代码实现**：`onMoveElement` 和 `onMoveElementToSibling` 函数

## 面板结构

动作面板分为四个主要标签页：

1. **组件标签页**：显示从Markdown生成的可用组件
2. **预设标签页**：根据元素类型显示可用的预设
3. **属性标签页**：显示核心样式属性控制
4. **移动标签页**：提供元素移动选项

## 与强化学习的集成

动作面板设计支持强化学习环境的关键需求：

1. **清晰的动作空间**：动作被分类成有限的类型，便于算法学习
2. **状态反馈**：每个动作都会即时更新布局，提供明确的状态转换
3. **可扩展性**：新的动作类型可以轻松添加到面板中

## 使用示例

```javascript
// 添加组件动作示例
onAddComponent(parentId, 'text', { 
  type: 'text', 
  content: { value: 'Hello World' },
  typographyPreset: 'h1' 
});

// 应用预设动作示例
onApplyCategoryPreset('typography', 'h2');

// 更新样式属性动作示例
onUpdateElementStyle(elementId, 'color', '#ff0000');

// 移动元素动作示例
onMoveElement(elementId, targetContainerId);
```

## 面板控制

动作面板可以通过UI顶部的按钮切换显示/隐藏，使界面在不需要时保持简洁，专注于布局预览。
